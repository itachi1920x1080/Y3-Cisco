# Y3 Cisco

Collection of Cisco Packet Tracer activities, lab exercises, and network configurations (`.pka` and `.pkt`) for Year 3 Networking coursework.

## Overview

This repository includes Packet Tracer files covering:
- **Routing & Switching**: VLANs, DTP, Trunking, Router-on-a-Stick, Layer 3 Switching, EtherChannel, and Spanning Tree Protocol (STP).
- **Dynamic Routing**: Single-Area OSPFv2 configuration, point-to-point links, DR/BDR election, and default route propagation.
- **Network Security**: Port security, switch security configuration, standard IPv4 ACLs (numbered and named), and extended IPv4 ACLs.
- **IP Services & High Availability**: DHCPv4, NAT for IPv4, and HSRP configuration.
- **Wireless Networking**: Basic WLANs on Wireless LAN Controllers (WLC), WPA2-Enterprise, and WLAN troubleshooting.
- **Network Design & Review**: Complete network topology designs and enterprise network simulations.
